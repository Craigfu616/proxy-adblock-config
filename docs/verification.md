# 第一版验证记录

日期：2026-11-17（Asia/Shanghai）。

## 环境与范围

- macOS，Mihomo Meta v1.19.33，使用本机已安装的内核启动独立测试进程。
- 测试使用临时目录、临时监听端口、本地 HTTP 服务和保留测试域名，没有修改运行中的客户端或系统代理。
- 上游广告列表从秋风公开地址实际下载。测试广告域名通过临时 hosts 指向本地服务，用于确认拒绝发生在规则层，没有访问广告服务器。
- 没有读取或上传个人节点、密码和订阅链接；代理路由验证使用本机不可用的测试 SOCKS 端口。
